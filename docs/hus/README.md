Este directorio contiene las HUs ejecutables del roadmap.

Cada HU debe poder entregarse a un agente de codigo sin contexto verbal extra. Por eso incluye objetivo, alcance, paths afectados, criterios de aceptacion, checklist tecnica y comandos de validacion.
