# ArgFit Desktop UI Kit (PrimeNG + Angular)

## Overview
Interactive desktop prototype demonstrating the ArgFit design system applied to PrimeNG framework patterns. Features full dashboard with sidebar navigation and multiple views.

## Screens
1. **Dashboard** — Analytics overview with charts, KPIs, device status
2. **Athletes** — Data table with search, filter, sort, pagination
3. **Devices** — Device management with status, firmware, configuration
4. **Reports** — Session reports with detailed metrics and export
5. **Settings** — System configuration with form controls

## Component Patterns (PrimeNG)
- Collapsible sidebar navigation with icon + label
- Breadcrumb navigation
- Data tables with headers, sort indicators, pagination
- Dialog modals with header, body, footer
- Toast notifications (top-right stack)
- Form layouts with floating labels
- Menu bars with dropdowns
- Card-based dashboard layout
