# ArgFit Mobile UI Kit (Ionic + Angular)

## Overview
Interactive mobile prototype demonstrating the ArgFit design system applied to Ionic framework patterns. Features three core screens with click-through navigation.

## Screens
1. **Home** — Dashboard with device status, quick stats, recent sessions
2. **Training** — Active training session with real-time data, timer, device connection
3. **Results** — Post-session analysis with charts, metrics, and export

## Component Patterns (Ionic)
- Bottom tab navigation with 5 tabs
- iOS-style status bar
- Full-width cards with 12px radius
- Floating labels on inputs
- Segment controls for data toggles
- Pull-to-refresh gesture area
- Safe-area padding for notch devices
- Haptic-style button press (scale 0.97)

## Usage
Open `index.html` to see the interactive prototype. Navigate between screens using the bottom tabs or in-screen buttons.
