## Características

```ts
import { AfImageCropperComponent } from '@argfit-ui/adaptive';
```

- Redimensionado por las cuatro esquinas, limitado a los bordes de la imagen.
- Movimiento del área mediante arrastre o teclado.
- Relaciones libres, cuadradas, circulares y panorámicas.
- Salida PNG, JPEG o WebP con dimensiones y calidad configurables.
- Interacción unificada mediante Pointer Events para ratón, lápiz y touch.
