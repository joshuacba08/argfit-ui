# CommandPalette

Paleta adaptativa para buscar rutas, resultados y acciones desde un único disparador. En desktop abre un overlay productivo mediante `Ctrl+K` o `Cmd+K`; en mobile ocupa la pantalla completa para conservar espacio y objetivos táctiles.

## Uso

```ts
import { AfCommandPalette } from '@argfit-ui/adaptive';
import type { AfCommandPaletteItem } from '@argfit-ui/core';
```

```html
<af-command-palette
  [items]="commands"
  (itemSelected)="runCommand($event)"
/>
```

La aplicación interpreta `kind`, `href` y `data`; la librería nunca navega, consulta APIs ni ejecuta lógica de negocio. Al seleccionar un item, la paleta emite el objeto, se cierra y limpia la consulta.

<Canvas of={CommandPaletteStories.Default} sourceState="shown" />

### Teclado

- `Ctrl+K` o `Cmd+K`: abre y enfoca la búsqueda desde cualquier lugar.
- Flechas, `Home` y `End`: cambian el resultado activo omitiendo elementos deshabilitados.
- `Enter`: selecciona; `Escape`: cierra y devuelve el foco.

Debe existir una sola instancia con `shortcutEnabled` activo por documento. Desactívalo en paletas secundarias.

## Composición

### Dentro de PageShell

Usa el slot de acciones existente y desactiva el buscador simple del shell:

```html
<af-page-shell [showSearch]="false" ...>
  <af-command-palette
    afPageShellActions
    [items]="commands"
    (itemSelected)="runCommand($event)"
  />
</af-page-shell>
```

### Fila personalizada

`afCommandPaletteItem` sustituye la presentación interior, pero la paleta conserva `role="option"`, estado activo, puntero y teclado.

```html
<af-command-palette [items]="commands">
  <ng-template afCommandPaletteItem let-item let-active="active" let-query="query">
    <app-command-result [item]="item" [active]="active" [query]="query" />
  </ng-template>
</af-command-palette>
```

No proyectes botones, enlaces ni otros controles interactivos dentro de la fila.

## Estados

Cada estado se muestra en su propio viewport de `38rem`: el overlay conserva su escala real y no compite con las demás variantes de la página.

### Abierta con grupos

Los grupos conservan el orden de su primera aparición y los elementos deshabilitados siguen visibles, pero se omiten durante la navegación por teclado.
