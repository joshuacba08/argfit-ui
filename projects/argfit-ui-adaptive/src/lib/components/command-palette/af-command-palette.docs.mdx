Host global de comandos inspirado en VS Code y Spotlight. La configuración declarativa describe qué existe; los ejecutores de la aplicación deciden cómo navegar, crear, llamar APIs o generar exportaciones.

## Arquitectura

```text
JSON/config ──► AfCommandPaletteService ──► un host visual
                      │
                      ├── ejecutores registrados ──► Router, APIs, exportadores
                      └── providers registrados  ──► resultados dinámicos
```

El JSON nunca contiene callbacks. La librería valida, busca, ordena y coordina la interacción; la aplicación conserva el routing, permisos, fetching y lógica de producto.

```ts
import { provideAfCommandPalette } from '@argfit-ui/core';
import { AfCommandPalette } from '@argfit-ui/adaptive';

bootstrapApplication(AppComponent, {
  providers: [provideAfCommandPalette(commandPaletteConfig)],
});
```

```html
<!-- Una sola vez, normalmente en el layout raíz -->
<af-command-palette (commandExecution)="trackCommand($event)" />
```

El atajo `Mod+K` se convierte en `Cmd+K` en macOS y `Ctrl+K` en el resto. Desde la raíz, `Escape` cierra y restaura el foco; dentro de subpaletas y parámetros, retrocede un paso.

## Registro Angular

```ts
import { inject } from '@angular/core';
import { Router } from '@angular/router';
import {
  provideAfCommandExecutor,
  provideAfCommandSearchProvider,
} from '@argfit-ui/core';

export const appConfig = {
  providers: [
    provideAfCommandExecutor('navigate', () => {
      const router = inject(Router);
      return ({ payload }) => router.navigateByUrl(String(payload?.['route']));
    }),
    provideAfCommandExecutor('export-report', () => async ({ parameters }) => {
      await exportReport(parameters['format'], parameters['from']);
    }),
    provideAfCommandSearchProvider('players-search', () => ({
      search: ({ query, signal }) => playersApi.search(query, { signal }),
    })),
  ],
};
```

Los ejecutores reciben el comando, `payload`, parámetros y un snapshot inmutable del contexto. Pueden ser síncronos o devolver una `Promise`. La paleta se cierra al despachar; un rechazo produce un evento de error, y la aplicación decide cómo mostrar feedback.

### Configuración y contexto en runtime

```ts
const palette = inject(AfCommandPaletteService);

palette.setConfig(configLoadedByTheApplication);
palette.setContext('auth.loggedIn', true);
palette.setContext('team.id', selectedTeam.id);
palette.removeContext('team.id');

palette.open({ modeId: 'commands', query: 'exportar' });
palette.clearHistory();
```

`registerExecutor` y `registerProvider` permiten registros en runtime y devuelven una función para desregistrarlos. Un `executorId` ausente mantiene el comando visible pero deshabilitado con un motivo accesible.

### Fila personalizada

```html
<af-command-palette>
  <ng-template afCommandPaletteCommand let-result let-active="active" let-mode="modeId">
    <app-command-result [result]="result" [active]="active" [mode]="mode" />
  </ng-template>
</af-command-palette>
```

La directiva solo reemplaza el interior visual; el host conserva `role="option"`, foco, puntero y teclado. No proyectes controles interactivos dentro de la fila.

## Flujos completos

Cada flujo se ejecuta en un viewport aislado y amplio. Así no compite por el atajo global ni registra múltiples hosts en la misma página.

### Ranking fuzzy

Prioriza label exacto/prefijo, label parcial, keywords, grupo y descripción. Prioridad, fijados e historial solo aportan bonos acotados.

### Atajo, prefijos e historial

## Migración V1 → V2

| V1 | V2 |
| --- | --- |
| `[items]` y `searchMode` por instancia | `provideAfCommandPalette(config)` y un catálogo global |
| `(itemSelected)` | ejecutor registrado por `executorId`; `(commandExecution)` es telemetría del host |
| `[(open)]` / `[(query)]` | `AfCommandPaletteService.open()`, `close()`, `toggle()` |
| `AfCommandPaletteItem` | `AfCommandDefinition` / `AfCommandPaletteResult` |
| `afCommandPaletteItem` | `afCommandPaletteCommand` |
| callbacks o routing en el consumidor del evento | JSON sin callbacks + ejecutores de aplicación |

El selector permanece como `<af-command-palette>`, pero ahora es el host de un servicio global. Elimina todas las instancias locales y conserva solo la del layout raíz.
