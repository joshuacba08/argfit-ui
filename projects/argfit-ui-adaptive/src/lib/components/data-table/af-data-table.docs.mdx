# DataTable

Compara colecciones de registros con una tabla productiva en desktop y una lista jerarquizada en mobile. Orden, paginación, selección y expansión comparten el mismo contrato público.

<div className="af-doc-callout">
  <strong>La aplicación conserva el estado</strong>

## Uso recomendado

```ts
import { AfDataTableComponent } from '@argfit-ui/adaptive';
import type { AfDataTableColumn, AfDataTableSort } from '@argfit-ui/core';
```

Úsala cuando una persona necesite comparar muchos registros con la misma estructura. Para un resumen corto usa `AfDataView`; para contenido libre con acciones independientes, usa una colección de tarjetas.

<Canvas of={DataTableStories.Default} sourceState="shown" />

### Diseño responsive por intención

DataTable no comprime una tabla de desktop. En mobile transforma cada fila en un registro legible y usa `mobilePriority` para decidir la jerarquía:

`valueLabel(row)` permite formatear el valor visible sin transformar el dataset, por ejemplo para añadir una unidad. Se aplica en ambas plataformas. Cambia la toolbar **Desktop/Mobile** de Storybook para verificar la jerarquía real.

### Orden y paginación

<Canvas of={DataTableStories.SortingAndPagination} sourceState="shown" />

El componente ordena y pagina el array recibido en `rows`. `sortChange` y `pageChange` notifican la intención, pero no mutan los inputs. Si los datos proceden de una API, la aplicación sigue siendo responsable del fetching, caché, filtros y errores; no ocultes esa lógica dentro de la tabla.

### Celdas y detalle de dominio

<Canvas of={DataTableStories.CustomContent} sourceState="shown" />

Proyecta componentes ArgFit en celdas cuando el valor necesite semántica visual. El contexto de `afDataTableCell` expone `value`, `row`, `column`, `rowId` y `rowIndex`; el detalle expone `row`, `rowId` y `rowIndex`.

<Canvas of={DataTableStories.Loading} sourceState="hidden" />

No combines `loading`, `error` y datos como mensajes externos desconectados: entrega un estado coherente a DataTable para mantener estructura y accesibilidad.

### Accesibilidad

<ul>
  <li>
    Proporciona un <code>ariaLabel</code> que identifique el dataset, no uno genérico como “tabla”.
  </li>
  <li>
    Las filas pueden activarse con <code>Enter</code> o <code>Espacio</code>; no implementes una
    segunda interacción sólo para ratón.
  </li>
  <li>
    La selección y la expansión tienen controles independientes de <code>rowPressed</code>.
  </li>
  <li>
    El estado de error usa <code>role="alert"</code> y la selección usa una región de estado.
  </li>
  <li>
    No uses color como único significado: compón texto con <code>AfBadge</code> para estados
    semánticos.
  </li>
</ul>

### Modelo controlado

```ts
sort: AfDataTableSort = { key: 'name', direction: 'asc' };
selectedRowIds: readonly string[] = [];

onSortChange(sort: AfDataTableSort): void {
  this.sort = sort;
}

onSelectionChange(ids: readonly string[]): void {
  this.selectedRowIds = ids;
}
```

```html
<af-data-table
  [columns]="columns"
  [rows]="athletes"
  [sort]="sort"
  selectionMode="multiple"
  [selectedRowIds]="selectedRowIds"
  ariaLabel="Disponibilidad del plantel"
  (sortChange)="onSortChange($event)"
  (selectionChange)="onSelectionChange($event)"
/>
```

## Theming

DataTable consume tokens semánticos de ArgFit y no expone estilos de PrimeNG o Ionic.
