# DatePicker

Entrada de fecha civil adaptativa. Usa un calendario compacto en desktop y el selector nativo de Ionic en mobile, manteniendo el mismo contrato de valor ISO `YYYY-MM-DD`.

## Características

```ts
import { AfDatePickerComponent } from '@argfit-ui/adaptive';
```

- Navegación diaria, mensual y anual con un layout consistente.
- Valor público ISO sin conversiones de zona horaria.
- Estados de ayuda, error, requerido, sólo lectura y deshabilitado.
- Renderer mobile con controles táctiles nativos.
