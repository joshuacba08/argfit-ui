Installation flow

The browser decides when the prompt is available. iOS uses Safari Add to Home Screen.

  1. Build with `ng build argfit-ui-pwa-starter --configuration production`.
  2. Serve `dist/argfit-ui-pwa-starter/browser` from localhost or HTTPS.
  3. Open the app in a compatible browser and install from the browser UI or prompt.
