# @argfit-ui/primitives

Vendor-agnostic primitive package for ArgFit UI.

Contains small building blocks shared by desktop, mobile, and adaptive layers. Primitives may depend on `@argfit-ui/core`, but must not import PrimeNG, Ionic, desktop, mobile, or adaptive implementations.

Current slice:

- `AfVisuallyHiddenComponent`

```bash
pnpm build:primitives
```
